# 001 — Product Overview & Project Vision

## 1. Executive Summary
CoinPilot AI is an institutional-grade crypto trading and portfolio management assistant deployed as a Telegram Mini App (TMA). It resolves the problem of market noise and cognitive overload by synthesizing technical analysis, order flow, liquidations, derivatives metrics, and macro sentiment into an automated Consensus Score (0–100) paired with actionable AI explanations.

---

## 2. Core Value Proposition
- **Multi-Factor Consensus Engine:** Converts complex market indicators into a unified score and direction (LONG/SHORT/NEUTRAL).
- **Institutional AI Explainer:** Utilizes LLMs (GPT-4o / Claude Haiku) strictly as an output formatter/explainer, eliminating AI hallucinations in quantitative financial calculations.
- **Telegram Native UX:** Seamless web-app interface within Telegram with freemium energy-based access control and viral referral tracking.
